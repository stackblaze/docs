# StackBlaze Docs

Public documentation for [StackBlaze](https://stackblaze.com), built with [Astro Starlight](https://starlight.astro.build/).

Live: [docs.stackblaze.com](https://docs.stackblaze.com)

```
npm install
npm run dev
```

Content lives in `src/content/docs/`. Sidebar IA is `astro.config.mjs`.
