---
title: Templates
description: One-click stacks that land on the project canvas.
---

Templates are pre-wired groups of services and databases. Deploy from the [template catalog](https://stackblaze.com/templates) or from **+ Service → Templates** on an existing canvas.

Fill in any prompted values, then [deploy staged changes](/deploy/staged-changes/). The canvas provisions every service the template defines.

You can save a live environment as a template from the canvas when you want to reuse a stack.

To describe a stack in git instead, use [config as code](/blueprint/).
