Manages the SSH public keys on your account. They are used by [`stackblaze ssh --native`](/cli/ssh/), `scp`, `sftp` and IDEs. Alias: `ssh-key`.

## Usage

```text
stackblaze ssh-keys list
stackblaze ssh-keys add [file] [--name <name>]
stackblaze ssh-keys remove <key>
```

| Subcommand | Description |
| --- | --- |
| `list` (alias `ls`) | The SSH keys on your account |
| `add [file]` | Add a public key. Default: `~/.ssh/id_ed25519.pub`, `id_ecdsa.pub` or `id_rsa.pub`. `-` reads the key from stdin |
| `remove <key>` (alias `rm`) | Remove a key by ID, fingerprint or name |

| Flag | Applies to | Description |
| --- | --- | --- |
| `--name <name>` | `add` | Key name (default: the key's comment, else `user@host`) |

Every subcommand accepts `--token`, `--api-url`, `-o, --output` and `--json` (see [scope and output flags](/cli/#scope-and-common-flags)).

When several keys have the same name, `remove` asks for the ID or fingerprint instead.

## Examples

```bash
stackblaze ssh-keys add
stackblaze ssh-keys add ~/.ssh/work.pub --name laptop
cat key.pub | stackblaze ssh-keys add -
stackblaze ssh-keys remove laptop
```
