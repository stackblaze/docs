---
title: stackblaze down
description: "Pause an app by scaling its web process to zero."
---

Scales the linked app's web process to 0 replicas. Nothing is deleted; scale back up with [`stackblaze scale`](/cli/scale/). Asks for confirmation unless you pass `-y`.

## Usage

```text
stackblaze down [options]
```

| Flag | Description |
| --- | --- |
| `-y, --yes` | Skip the confirmation |
| `--build <name>` | Also delete this build (see `stackblaze builds list`) |

Also accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --pipeline`, `--phase`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

## Example

```bash
stackblaze down -y
stackblaze scale -r 1     # bring it back
```
