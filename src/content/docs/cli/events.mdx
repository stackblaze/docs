---
title: stackblaze events
description: "Show recent platform events for an app."
---

Prints the linked app's recent events (reason and message). Useful when an app does not start.

## Usage

```text
stackblaze events [-n <limit>] [--all] [options]
```

| Flag | Description |
| --- | --- |
| `-n, --limit <n>` | Show the newest `n` events (text default `20`; `-o json` returns every event unless you pass `-n`) |
| `--all` | Include events of the deploy placeholder pod (hidden by default) |

Also accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --project`, `-e, --env`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.
