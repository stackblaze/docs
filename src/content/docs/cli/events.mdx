---
title: stackblaze events
description: "Show recent platform events for an app."
---

Prints the linked app's recent events (reason and message). Useful when an app does not start.

## Usage

```text
stackblaze events [options]
```

Also accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --pipeline`, `--phase`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.
