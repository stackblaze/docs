---
title: stackblaze status
description: "Check the API connection and whether Infrastructure as Code is enabled."
---

Checks that the API is reachable with your credentials and reports whether Infrastructure as Code ([plan](/cli/plan/), [apply](/cli/apply/), [export](/cli/export/), [destroy](/cli/destroy/)) is enabled. Pass `--pipeline` (or run in a linked directory) to check one project.

## Usage

```text
stackblaze status [options]
```

Also accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --pipeline`, `--phase`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

Exits `1` when Infrastructure as Code is reported as disabled.
