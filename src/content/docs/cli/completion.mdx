---
title: stackblaze completion
description: "Generate shell completion for bash, zsh or fish."
---

Prints a completion script for your shell to stdout.

## Usage

```text
stackblaze completion bash|zsh|fish
```

## Install

```bash
# bash
stackblaze completion bash > ~/.local/share/bash-completion/completions/stackblaze
# or, in ~/.bashrc:  source <(stackblaze completion bash)

# zsh
stackblaze completion zsh > "${fpath[1]}/_stackblaze"
# or, in ~/.zshrc:   source <(stackblaze completion zsh)

# fish
stackblaze completion fish > ~/.config/fish/completions/stackblaze.fish
```

Regenerate the script after upgrading to pick up new commands.
