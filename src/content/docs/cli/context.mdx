---
title: stackblaze context
description: "Show the API URL, pipeline, phase and app the CLI resolves here."
---

Prints what the CLI would use in this directory: the API URL and the pipeline, phase and app after applying flags, `STACKBLAZE_*` environment variables and `.stackblaze/project.json` (see [scope](/cli/#scope-and-common-flags)).

## Usage

```text
stackblaze context [options]
```

Also accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --pipeline`, `--phase`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

Needs credentials (it reads the API URL from them) but makes no API call.
