---
title: stackblaze export
description: "Write live pipelines and apps out as manifest files."
---

Writes one YAML file per pipeline (`<pipeline>.pipeline.yaml`) and per app (`<pipeline>.<phase>.<app>.app.yaml`) that [`plan`](/cli/plan/) and [`apply`](/cli/apply/) accept.

## Usage

```text
stackblaze export [--out <dir>] [-p <pipeline>] [-o text|json]
```

| Flag | Description |
| --- | --- |
| `--out <dir>` | Output directory (default `stackblaze`) |
| `-p, --pipeline <name>` | Export one pipeline (default: all you can see) |

Also accepts `--token`, `--api-url`, `-o, --output` and `--json` (see [common flags](/cli/#scope-and-common-flags)).

Infrastructure as Code must be enabled. Exported app specs include variable values; review the files before committing them.

```bash
stackblaze export --out ./infra -p shop
```
