---
title: stackblaze logout
description: "Delete the saved CLI credentials from this machine."
---

Deletes the saved credentials file (`~/.config/stackblaze/config.json`, or `STACKBLAZE_CONFIG`). The token itself is not revoked; revoke it in the dashboard under **Settings → API tokens**.

## Usage

```text
stackblaze logout [-o text|json]
```

`STACKBLAZE_TOKEN` and `STACKBLAZE_API_URL` in your environment are not affected.
