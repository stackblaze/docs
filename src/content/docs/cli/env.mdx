## `env pull`

Writes the linked app's variables to a dotenv file (default `.env.local`). It will not overwrite an existing file unless you pass `--force`.

```text
stackblaze env pull [--out <file>] [--force] [--include-metadata]
```

| Flag | Description |
| --- | --- |
| `--out <file>` | Output path (default `.env.local`) |
| `--force` | Overwrite the file if it exists |
| `--include-metadata` | Also write `STACKBLAZE_PIPELINE`, `STACKBLAZE_PHASE` and `STACKBLAZE_APP` |

Also accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --pipeline`, `--phase`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

```bash
stackblaze env pull --out .env --force
```

The file contains secrets in plain text; keep it out of git.
