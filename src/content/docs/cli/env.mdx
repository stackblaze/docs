## `env pull`

Writes the linked app's variables to a dotenv file (`[path]` or `--out`, default `.env.local`). Variables the platform injects into every app are left out unless you pass `--all`. It will not overwrite an existing file unless you pass `--force`.

```text
stackblaze env pull [path] [--out <file>] [--force] [--include-metadata] [--all]
```

| Flag | Description |
| --- | --- |
| `--out <file>` | Output path (default `.env.local`; or pass it positionally) |
| `--force` | Overwrite the file if it exists |
| `--all` | Also write platform-injected variables (hidden by default) |
| `--include-metadata` | Also write `STACKBLAZE_PIPELINE`, `STACKBLAZE_PHASE` and `STACKBLAZE_APP` |

Also accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --project`, `-e, --env`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

```bash
stackblaze env pull --out .env --force
```

The file contains secrets in plain text; keep it out of git.
