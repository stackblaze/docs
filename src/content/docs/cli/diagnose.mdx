---
title: stackblaze diagnose
description: "Check an app's configuration, metrics, logs and add-ons for problems."
---

Collects the linked app's configuration, resource metrics, recent logs and add-on state, and reports findings and hints.

## Usage

```text
stackblaze diagnose [options]
```

| Flag | Description |
| --- | --- |
| `--scale <window>` | Metrics window: `2h` (default), `24h` or `7d` |
| `--log-minutes <n>` | Log search window in minutes |

Also accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --pipeline`, `--phase`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

```bash
stackblaze diagnose --scale 24h
```
