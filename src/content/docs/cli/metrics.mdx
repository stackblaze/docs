---
title: stackblaze metrics
description: "Show current CPU and memory usage per pod."
---

Prints current CPU (millicores) and memory (MiB) for each of the linked app's pods.

## Usage

```text
stackblaze metrics [options]
```

Also accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --pipeline`, `--phase`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

For history and analysis, use [`stackblaze diagnose`](/cli/diagnose/) or the dashboard.
