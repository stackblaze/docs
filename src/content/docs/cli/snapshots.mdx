---
title: stackblaze snapshots
description: "List and create volume snapshots for an app."
---

Alias: `snapshot`.

## Usage

```text
stackblaze snapshots list
stackblaze snapshots create [--group-id <id>]
```

| Subcommand | Description |
| --- | --- |
| `list` | Snapshots of the app's volumes |
| `create` | Snapshot every snapshot-capable volume of the app as one group. Your platform admin may turn this off |

| Flag | Applies to | Description |
| --- | --- | --- |
| `--group-id <id>` | `create` | Custom snapshot group ID |

Every subcommand accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --project`, `-e, --env`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

## Example

```bash
stackblaze snapshots create --group-id before-migration
stackblaze snapshots list
```

`snapshots restore` was removed: a restore never replaces a running volume. To get data back, create new volumes (and databases) from a recovery point with [`stackblaze backups restore`](/cli/backups/), then attach them when you are ready.
