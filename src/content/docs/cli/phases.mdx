---
title: stackblaze phases
description: "List, create, delete and switch phases (environments) of a pipeline."
---

Phases are a pipeline's environments, such as `staging` and `production`. Alias: `phase`.

## Usage

```text
stackblaze phases list
stackblaze phases create <name>
stackblaze phases delete <name> [-y]
stackblaze phases use [name]
```

| Subcommand | Description |
| --- | --- |
| `list` | Phases of the pipeline |
| `create <name>` | Add a phase |
| `delete <name>` | Remove a phase; asks you to type its name unless `-y`. Apps in the phase are not deleted. You cannot delete a pipeline's only phase |
| `use [name]` | Switch the phase in this directory's link (`.stackblaze/project.json`); without a name, pick from a list |

Every subcommand accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --pipeline`, `--phase`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

## Examples

```bash
stackblaze phases create staging
stackblaze phase use staging
stackblaze phases delete preview -y
```
