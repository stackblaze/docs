---
title: stackblaze ssh
description: "Open an interactive shell inside a running app container."
---

Opens an interactive terminal in one of the linked app's pods over the API (no SSH keys or open ports). Remote console access must be enabled on the platform; if it is not, the command reports a console error.

## Usage

```text
stackblaze ssh [options]
```

| Flag | Description |
| --- | --- |
| `--pod <name>` | Pod to connect to (default: the app's first pod) |
| `--container <name>` | Container (default: `kuberoapp-web`, else the first container) |
| `--command <shell>` | Command to start (default `sh`) |

Also accepts `-p, --pipeline`, `--phase`, `-a, --app`, `--token` and `--api-url` (see [scope](/cli/#scope-and-common-flags)). No JSON output.

## Examples

```bash
stackblaze ssh
stackblaze ssh --command bash -a worker
```

The CLI exits with the remote session's exit code.
