---
title: stackblaze domain
description: "List, set, check and remove an app's custom domains."
---

Alias: `domains`. `stackblaze domain` with no subcommand lists the app's hosts.

## Usage

```text
stackblaze domain
stackblaze domain add <host>
stackblaze domain status [host]
stackblaze domain remove <host> [-y]
```

| Subcommand | Description |
| --- | --- |
| *(none)* | List the app's hosts |
| `add <host>` | Make `host` the app's domain. This **replaces** the app's current hosts |
| `status [host]` | Ingress state, hosts, whether each host has a TLS entry, and the pipeline's wildcard domain |
| `remove <host>` | Remove a host. Removing the last host turns off the app's public ingress, so it asks for confirmation unless `-y` |

Every subcommand accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --pipeline`, `--phase`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

## Examples

```bash
stackblaze domain add www.example.com
stackblaze domain status www.example.com
stackblaze domain remove old.example.com
```

DNS setup is covered in [Custom domains](/networking/custom-domains/).
