---
title: stackblaze mcp
description: "Alias of stackblaze setup mcp."
---

`stackblaze mcp` is the same command as [`stackblaze setup mcp`](/cli/setup/): it adds a `stackblaze` MCP server to your editor or coding agent.

```text
stackblaze mcp [--ide cursor|claude|codex|vscode|windsurf|opencode|copilot] [--print]
```

The config file it writes contains your API token. See [setup](/cli/setup/) for details and [MCP server](/ai/mcp/) for the tools it exposes.
