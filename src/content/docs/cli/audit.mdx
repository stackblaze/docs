---
title: stackblaze audit
description: "Show the audit trail: who did what, and when."
---

Prints recent audit log entries. When an app is in scope (flags, environment or a linked directory) it shows that app's entries; otherwise your organization's. Text mode shows the newest 20; `-o json` returns everything fetched.

## Usage

```text
stackblaze audit [options]
```

| Flag | Description |
| --- | --- |
| `--action <keyword>` | Only entries whose action contains this text, e.g. `delete`, `scale` |
| `--actor <user>` | Only entries whose actor contains this text |
| `--since-minutes <n>` | Only entries from the last `n` minutes |
| `-n, --limit <n>` | Entries to fetch before filtering (default `100`) |

Also accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --pipeline`, `--phase`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

```bash
stackblaze audit --action delete --since-minutes 1440
```
