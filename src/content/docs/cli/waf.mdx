---
title: stackblaze waf
description: "Show and change App Shield (web application firewall) for an app."
---

App Shield is the per-app web application firewall. `stackblaze waf` with no subcommand shows its status.

## Usage

```text
stackblaze waf [status]
stackblaze waf enable
stackblaze waf disable
stackblaze waf under-attack status|enable|disable
```

| Subcommand | Description |
| --- | --- |
| `status` | Whether App Shield is on, and its mode |
| `enable` | Turn on App Shield in detection-only mode (keeps blocking mode if it is already on) |
| `disable` | Turn off App Shield |
| `under-attack status` | Whether Under Attack Mode (blocking) is on |
| `under-attack enable` | Block matching requests |
| `under-attack disable` | Return to detection-only |

Every subcommand accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --pipeline`, `--phase`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

See [App Shield](/networking/waf/).
