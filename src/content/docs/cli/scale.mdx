---
title: stackblaze scale
description: "Set the web or worker replica count of an app."
---

Sets the replica count of the linked app's web or worker process. `0` stops that process. Same command as `stackblaze apps scale`.

## Usage

```text
stackblaze scale -r <n> [--process web|worker] [options]
```

| Flag | Description |
| --- | --- |
| `-r, --replicas <n>` | Replica count, `0` to `50` (required) |
| `--process <name>` | `web` (default) or `worker` |

Also accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --pipeline`, `--phase`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

## Examples

```bash
stackblaze scale -r 3
stackblaze scale -r 1 --process worker -a jobs
```
