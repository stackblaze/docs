---
title: stackblaze restart
description: "Rolling restart of an app without rebuilding."
---

Restarts the linked app's pods with the same image. Nothing is built or pulled. Same command as `stackblaze apps restart`.

## Usage

```text
stackblaze restart [options]
```

Also accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --pipeline`, `--phase`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

To build or pull a new version, use [`stackblaze redeploy`](/cli/redeploy/).
