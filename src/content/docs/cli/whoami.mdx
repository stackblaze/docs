---
title: stackblaze whoami
description: "Show the signed-in user, API URL and pipeline count."
---

Shows which API you are talking to and who you are: email, username, the number of pipelines you can see, and whether Infrastructure as Code is enabled.

## Usage

```text
stackblaze whoami [options]
```

Also accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --pipeline`, `--phase`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

With `--pipeline`, the Infrastructure as Code line reports that project.

## Example

```bash
stackblaze whoami -o json | jq -r .user.email
```

Exit code `2` means no credentials or a rejected token.
