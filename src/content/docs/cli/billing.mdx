Prints your plan, usage credit and current resource usage (CPU, memory and more).

## Usage

```text
stackblaze billing [options]
```

Also accepts the [scope and output flags](/cli/#scope-and-common-flags): `-p, --pipeline`, `--phase`, `-a, --app`, `--token`, `--api-url`, `-o, --output`, `--json`.

```bash
stackblaze billing -o json
```

Manage payment and plans in the dashboard.
