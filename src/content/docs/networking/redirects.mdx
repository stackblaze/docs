---
title: Redirects & Rewrites
description: Handle URL redirects and rewrites in your service, in application code or in the web server that serves your files.
---

StackBlaze has no redirect rules of its own and does not read a `_redirects` file. Handle redirects and rewrites in your service: in application code, or in the web server that serves your files.

## Static sites

A [static site](/deploy/static-sites/) on StackBlaze is a container that serves files, for example nginx. Put redirects and the single-page-app fallback in its config:

```nginx title="nginx.conf"
server {
  listen 8080;
  root /usr/share/nginx/html;

  # 301 redirects
  location = /old-path { return 301 /new-path; }
  location /blog/      { rewrite ^/blog/(.*)$ /posts/$1 permanent; }

  # SPA fallback: serve index.html for client-side routes
  location / {
    try_files $uri $uri/ /index.html;
  }
}
```

## Application-level redirects

For services built from Node.js, Python, Go and similar, implement redirects in your application code. Your service receives every request and can respond however it likes.

### Express (Node.js)

```ts title="server.ts"
// Permanent redirect
app.get('/old-path', (req, res) => {
  res.redirect(301, '/new-path')
})

// Conditional redirect based on query param
app.get('/login', (req, res) => {
  if (req.query.next) {
    res.redirect(`/auth?return=${encodeURIComponent(req.query.next as string)}`)
  } else {
    res.redirect('/auth')
  }
})

// Redirect old subdirectory to new location
app.use('/legacy', (req, res) => {
  const newPath = req.path.replace('/legacy', '/app')
  res.redirect(301, newPath)
})
```

### Next.js (next.config.js)

```js title="next.config.js"
/** @type {import('next').NextConfig} */
module.exports = {
  async redirects() {
    return [
      {
        source: '/blog/:slug',
        destination: '/posts/:slug',
        permanent: true, // 308 (permanent, preserves HTTP method)
      },
      {
        source: '/about',
        destination: '/company/about',
        permanent: false, // 307 (temporary)
      },
    ]
  },
  async rewrites() {
    return [
      {
        source: '/api/:path*',
        destination: 'http://api:3000/:path*', // Proxy to internal service
      },
    ]
  },
}
```

### Django

```python title="urls.py"
from django.views.generic import RedirectView
from django.urls import path, re_path

urlpatterns = [
    # Simple redirect
    path('old-path/', RedirectView.as_view(url='/new-path/', permanent=True)),

    # Regex redirect preserving path segments
    re_path(r'^blog/(?P<slug>[\w-]+)/$',
            RedirectView.as_view(url='/posts/%(slug)s/', permanent=True)),
]
```

## www redirect

To send `www.example.com` to `example.com` (or the other way), add both as [custom domains](/networking/custom-domains/) on the same service, then redirect on the `Host` header in your app or web server:

```ts title="server.ts"
app.use((req, res, next) => {
  if (req.hostname === 'www.example.com') {
    return res.redirect(301, `https://example.com${req.originalUrl}`)
  }
  next()
})
```
