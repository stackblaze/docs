Three catalog entries speak the MongoDB wire protocol:

| Entry | Engine | Versions | Topology |
| --- | --- | --- | --- |
| **MongoDB** | Official `mongo` image | 8.0 (default), 7.0 | One instance |
| **FerretDB** | FerretDB on PostgreSQL with the DocumentDB extension | FerretDB 2.7 | Two FerretDB proxies, HA available for the PostgreSQL backend |
| **Document DB** | Microsoft DocumentDB on PostgreSQL | Preview | One instance |

You connect to all three with the standard MongoDB drivers and tools (mongosh, Compass, Mongoose, Prisma, Motor). FerretDB and DocumentDB are MongoDB-compatible, not MongoDB itself: check that the features your app uses are supported before you move to them.

## Creating a database

From **+ Service → Databases**, add **MongoDB**, **FerretDB**, or **Document DB**. It appears on the canvas as a staged change. Apply your staged changes and StackBlaze creates it with the catalog defaults.

To connect a service, open the database, go to **Settings → Connection**, and switch the service on.

## Connection variables

| Variable | MongoDB | FerretDB | Document DB |
| --- | --- | --- | --- |
| `MONGO_HOST` | Internal hostname | Internal hostname | Internal gateway hostname |
| `MONGO_PORT` | `27017` | `27017` | `10260` |
| `MONGO_USERNAME` | `mongoadmin` | `ferretdb` | `mongoadmin` |
| `MONGO_PASSWORD` | From a secret | From a secret | From a secret |
| `MONGO_DATABASE` | `app` | `app` | Not set |
| `MONGODB_URI`, `MONGO_URL`, `DATABASE_URL` | From a secret | From a secret | Only when the password is part of the definition |

Read the URI from `MONGODB_URI` (or `MONGO_URL`) rather than hardcoding a host and port. Document DB requires TLS and SCRAM-SHA-256 on port `10260`, so a hardcoded `mongodb://host:27017` does not work there.

```text title="MongoDB (internal)"
mongodb://mongoadmin:password@[service-name]:27017/?authSource=admin
```

### From your machine

**Settings → Access** shows the connection details and an environment snippet. **Public access** makes the database reachable from outside the platform, only from the IP addresses you allow, with TLS. The CLI equivalent is `stackblaze addons expose <addon> --allow <ip/cidr>`; `stackblaze addons info <addon> --reveal` prints the URI.

## High availability (FerretDB)

Open the FerretDB database, go to **Settings → HA**, and click **Enable HA**. Its PostgreSQL backend grows to 3 instances with streaming replication. HA needs a plan with database high availability (Pro or Business) and is one-way. A FerretDB created on the older single-server backend cannot turn HA on: restore a backup of it as a new FerretDB first.

The official MongoDB image and Document DB have no HA.

Enable retryable writes in your client so it rides through a failover:

```ts title="Mongoose connection (with retryable writes)"
import mongoose from 'mongoose'

await mongoose.connect(process.env.MONGODB_URI!, {
  retryWrites: true,
  w: 'majority',
})
```

## Backups

Backups are off until you turn on a schedule for the environment. Recovery points hold a dump of each MongoDB and FerretDB database and a copy of a Document DB volume. A restore always creates a new database next to the running one. See [Backups & recovery](/databases/backups/).

## Indexes

Create indexes in your application startup code or migration scripts.

```ts title="Create indexes (Mongoose)"
const userSchema = new mongoose.Schema({
  email: { type: String, unique: true, index: true },
  createdAt: { type: Date, index: true },
  'profile.city': { type: String },
})

// Compound index
userSchema.index({ 'profile.city': 1, createdAt: -1 })
```

## Connecting with common ODMs

### Mongoose

```ts title="db.ts"
import mongoose from 'mongoose'

if (mongoose.connection.readyState === 0) {
  await mongoose.connect(process.env.MONGODB_URI!, {
    serverSelectionTimeoutMS: 5000,
    socketTimeoutMS: 45000,
  })
}
```

### Prisma (MongoDB provider)

```prisma title="prisma/schema.prisma"
datasource db {
  provider = "mongodb"
  url      = env("MONGODB_URI")
}

model User {
  id    String @id @default(auto()) @map("_id") @db.ObjectId
  email String @unique
  name  String
}
```

### Motor (Python async)

```python title="database.py"
from motor.motor_asyncio import AsyncIOMotorClient
import os

client = AsyncIOMotorClient(os.environ["MONGODB_URI"])
db = client["app"]
```
