Managed Milvus, an open-source vector database for embeddings and similarity search, run by the Milvus operator.

## Creating a Milvus instance

From **+ Service → Databases**, add **Milvus**. It appears on the canvas as a staged change. Apply your staged changes and StackBlaze creates it in standalone mode.

Milvus is a vector database: it stores high-dimensional embeddings and finds the most similar vectors to a query, which makes it a common building block for AI features such as semantic search, recommendations, and retrieval-augmented generation (RAG).

To connect a service, open the database, go to **Settings → Connection**, and switch the service on. The service gets `MILVUS_HOST`, `MILVUS_PORT` (`19530`), and `MILVUS_URI` / `MILVUS_URL` (`http://host:19530`).

## Connecting

Milvus speaks gRPC and listens on port `19530`. Services in the same environment connect over the private network. `MILVUS_URI` points at this address.

```text title="MILVUS_URI (internal)"
http://[service-name]-milvus:19530
```

## Topology

New Milvus databases run in **standalone** mode: one process holds the query, data, and index roles. Milvus has no **Enable HA** switch in the dashboard.

## Connecting from Python

Install `pymilvus` and read the connection target from `MILVUS_URI`. The snippet below connects, creates a collection with a vector field, inserts nothing yet, and runs a similarity search.

```python title="milvus_example.py"
import os
from pymilvus import MilvusClient, DataType

client = MilvusClient(uri=os.environ["MILVUS_URI"])

# Create a collection with a 768-dimensional vector field
schema = client.create_schema(auto_id=True)
schema.add_field("id", DataType.INT64, is_primary=True)
schema.add_field("embedding", DataType.FLOAT_VECTOR, dim=768)

client.create_collection("documents", schema=schema)
client.create_index(
    "documents",
    index_params=client.prepare_index_params(
        field_name="embedding",
        index_type="IVF_FLAT",
        metric_type="L2",
    ),
)
client.load_collection("documents")

# Search for the 5 nearest vectors to a query embedding
query = [[0.1] * 768]
results = client.search(
    "documents",
    data=query,
    anns_field="embedding",
    limit=5,
)
print(results)
```

## Backups

Backups are off until you turn on a schedule for the environment. Recovery points hold a copy of the database's volumes. A restore always creates a new database next to the running one. See [Backups & recovery](/databases/backups/).
