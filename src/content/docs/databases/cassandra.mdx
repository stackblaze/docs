Managed Apache Cassandra (4.1.7), a wide-column distributed database, run by the Cassandra operator.

## Creating a Cassandra database

From **+ Service → Databases**, add **Cassandra**. It appears on the canvas as a staged change. Apply your staged changes and StackBlaze creates it with the catalog defaults: one node with a 10 GB volume.

To connect a service, open the database, go to **Settings → Connection**, and switch the service on.

## Connecting

Cassandra uses the CQL binary protocol on port `9042`. A connected service gets `CASSANDRA_HOST` and `CASSANDRA_PORT`, plus the same values as `CQL_HOST` / `CQL_PORT` and `SCYLLA_HOST` / `SCYLLA_PORT`. Services in the same environment reach it over the private network:

```text title="Contact point (internal)"
[service-name]:9042
```

Connect using a CQL driver for your language, or the `cqlsh` command line shell pointed at the same contact point and port.

## Topology

A new Cassandra database is a single node. Cassandra has no **Enable HA** switch in the dashboard. With one node, use a replication factor of 1 for your keyspaces.

## Connecting from Python

Install the `cassandra-driver` package, read the host and port from the environment, and connect:

```python title="app.py"
import os
from cassandra.cluster import Cluster

cluster = Cluster(
    [os.environ["CASSANDRA_HOST"]],
    port=int(os.environ["CASSANDRA_PORT"]),
)
session = cluster.connect()

session.execute(
    "CREATE KEYSPACE IF NOT EXISTS app "
    "WITH replication = {'class': 'SimpleStrategy', 'replication_factor': 1}"
)
session.set_keyspace("app")

session.execute(
    "CREATE TABLE IF NOT EXISTS users (id uuid PRIMARY KEY, name text)"
)

rows = session.execute("SELECT release_version FROM system.local")
print(rows.one().release_version)

cluster.shutdown()
```

## Backups

Backups are off until you turn on a schedule for the environment. Recovery points hold a copy of the database's volumes. A restore always creates a new database next to the running one. See [Backups & recovery](/databases/backups/).
