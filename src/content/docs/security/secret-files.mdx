---
title: Secret Files
description: StackBlaze has no separate secret-file feature. How to get a credential file, such as a service account JSON key, into a service.
---

StackBlaze does not have a separate secret-file feature. There is no form that takes a file and mounts it read-only at a path.

Some libraries want a file, not an environment variable (a Google service account JSON key, a TLS key pair, an SSH key). Two things work today.

## Keep the contents in a variable

Store the file contents in a [variable](/security/env-vars/). Variable values are stored in the service's own secret and masked in the dashboard and API.

Write the file when the container starts, then point the library at it:

```bash title="start command"
printf '%s' "$GCP_SA_JSON" > /tmp/gcp-sa.json
export GOOGLE_APPLICATION_CREDENTIALS=/tmp/gcp-sa.json
exec node dist/server.js
```

For binary files, store the value base64-encoded and decode it at start (`base64 -d`).

## Upload it to a volume

Attach a [volume](/storage/persistent-disks/) to the service and upload the file with the volume file browser or the CLI (`stackblaze files upload`). The file is a plain file on the volume. It is not encrypted separately, and anyone who can open the service's files can read it. Prefer a variable for credentials.
