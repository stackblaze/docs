---
title: IP Allowlisting
description: Allow or block visitor IP ranges for a service with inbound IP rules.
---

Inbound IP rules limit which source IPs can reach a service. They are checked at the edge, before a request reaches your app. Requests that are not allowed get HTTP 403.

The rules apply to a service's public traffic only. There is no IP allowlist for the StackBlaze dashboard or API.

:::note[Business plan]
Inbound IP rules are part of **Advanced networking**, which is included on the Business plan. See [limits](/reference/limits/#plan-gated-features).
:::

## Set inbound IP rules

1. Open the service on the canvas → **Settings → Network**.
2. Open **Advanced networking** and find **Inbound IP rules**.
3. Fill in one or both fields:
   - **Allowed IP ranges** — comma-separated IPv4 CIDRs. When set, every other IP gets a 403. Include your own address.
   - **Blocked IP ranges** — comma-separated IPv4 CIDRs to reject with 403.
4. Save and deploy the change.

```text title="Example"
Allowed IP ranges: 203.0.113.0/24, 198.51.100.7/32
```

## Using a VPN

If your team reaches the service through a VPN, allow the VPN's egress ranges instead of each person's home IP.

## What is not affected

- Private traffic between services in the same environment
- Database connections from your services
- The dashboard, API, and CLI
