---
title: Support
description: How to get help.
---

- **Docs** — this site. Search with `Ctrl K` / `⌘ K`.
- **Dashboard** — in-product help and status on the service (build logs, runtime logs, Coroot).
- **Email / ticket** — Libredesk from the dashboard or [stackblaze.com](https://stackblaze.com).
- **Status** — platform incidents are posted on the status page linked from the dashboard.

Include the **project**, **environment**, **service**, and a deployment / revision id when you write in. Do not send kubectl output — we cannot use it, and you should not have cluster access.

Enterprise plans get a dedicated SLA. See [Pricing](/reference/pricing/).
