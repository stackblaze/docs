title: Keyboard shortcuts
description: Shortcuts in the dashboard, on the project canvas, and in these docs.
---

On macOS use `⌘`; on Windows and Linux use `Ctrl`.

## Dashboard

| Shortcut | Action |
| --- | --- |
| `⌘ B` / `Ctrl B` | Toggle the navigation sidebar |

## Project canvas

These work when you can edit the project and the focus is not in a text field. They do nothing while a sheet or dialog is open.

| Shortcut | Action |
| --- | --- |
| `⌘ K` / `Ctrl K` | Open or close the add menu (same as **+ Service**) |
| `⌘ A` / `Ctrl A` | Select every card on the canvas |
| `Esc` | Clear the selection |
| `Enter` | Review and commit staged changes (when there are any) |
| `⌘ Enter` / `Ctrl Enter` | Deploy the selected cards |
| `⌘ Backspace` / `Ctrl Backspace` | Delete the selected cards |
| `⌘ Shift Backspace` / `Ctrl Shift Backspace` | Discard staged changes on the selected cards |
