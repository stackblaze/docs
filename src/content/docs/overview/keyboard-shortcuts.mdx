---
title: Keyboard shortcuts
description: Documented shortcuts in the dashboard and in these docs.
---

We do not ship a separate mobile app, and the canvas does not currently expose a command palette.

| Shortcut | Where | Action |
| --- | --- | --- |
| `⌘ B` / `Ctrl B` | Dashboard | Toggle the navigation sidebar |
| `⌘ K` / `Ctrl K` | These docs | Open search |

Dashboard context menus may show extra item shortcuts when a menu is open. Those are listed on the menu itself.
