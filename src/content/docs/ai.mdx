StackBlaze exposes the same control plane the dashboard uses, so an agent in your editor or terminal can create projects, add services, deploy, and read logs.

- **[MCP server](/ai/mcp/)**: `https://mcp.stackblaze.cloud/mcp` with an `sb_pat_` bearer token. Tool names are unprefixed (`get_app`, `deploy_app`, `search_logs`).
- **[Connectors](/ai/connectors/)**: Cursor, Claude Code, Codex, VS Code, Windsurf, OpenCode, and other MCP clients.
- **CLI**: `stackblaze setup mcp`, `stackblaze setup skills`, `stackblaze setup agent`, and `stackblaze agent` for a chat in your terminal. See [stackblaze setup](/cli/setup/) and [stackblaze agent](/cli/agent/).

To run an agent of your own on StackBlaze (instructions, a team chat, an API, and triggers), see [AI agents](/ai-agents/).

The top-level [StackBlaze for Agents](/agents/) page is the short version of this.
