The [CLI](/cli/) (`stackblaze`) is the supported command-line client. It calls the same REST API as the dashboard. Tokens use the `kbr_pat_` prefix (or the token `stackblaze login` stores).

This page is the HTTP/API companion — useful in CI when you would rather `curl` than install a binary.

```bash title="terminal"
export STACKBLAZE_TOKEN=kbr_pat_…

curl -sS https://api.stackblaze.cloud/api/pipelines \
  -H "Authorization: Bearer $STACKBLAZE_TOKEN"
```

Interactive OpenAPI: [https://api.stackblaze.cloud/api/docs](https://api.stackblaze.cloud/api/docs). MCP: [mcp.stackblaze.cloud](https://mcp.stackblaze.cloud).

Install and command reference: [CLI](/cli/). IaC file format: [Config as code](/blueprint/).
