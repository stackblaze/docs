title: Nuxt
description: Deploy Nuxt on StackBlaze from GitHub or a Dockerfile.
---

Add a service from your Nuxt repo. Railpack detects **node** from `package.json`. If the service root has a `Dockerfile`, StackBlaze builds from it instead.

Use the Nitro Node preset. With no `start` script, Railpack runs `node .output/server/index.mjs`, which listens on `PORT`.

## Deploy from GitHub

1. [Dashboard](https://dashboard.stackblaze.cloud) → **New Project** (or open an existing canvas).
2. **+ Service → GitHub repository**. Pick the repo and branch.
3. Click **Commit 1 change**, review the [staged changes](/deploy/staged-changes/), and **Deploy**.
4. A service exposed to the internet gets a `*.stackblaze.app` URL. Attach a [custom domain](/networking/custom-domains/) if you want your own.

StackBlaze sets `PORT` to the service port and pre-fills `3000` for Nuxt repos. If detection is wrong, change **Build method**, **Build command**, or **Start command** on the service. Typical start: `node .output/server/index.mjs`.

## Docker

If you already have a `Dockerfile`, StackBlaze uses it. The process must listen on `PORT`.

## Data

**+ Service → Database or cache** for PostgreSQL, MariaDB, Valkey, and more. Wire `DATABASE_URL` from the service **Variables** tab or `fromDatabase` in [stackblaze.yaml](/blueprint/).

## CLI

```bash
stackblaze login
stackblaze init
stackblaze up
```

See the [CLI](/cli/).
